# Contributing to Vigilant Agent Hive

1. **Setup Requirements**: Rust 1.75+, Docker
2. **Build Process**: `make build`
3. **Testing**: Run `make test` for unit tests and `make e2e` for integration tests
4. **Code Style**: Use `make lint` before PRs

## Design Review Process
All core implementation changes require RFC approval. See `docs/rfcs/` for current pending proposals.

## Security Vulnerabilities
Report privately via our Vulnerability Disclosure Program at https://security.vigilant-hive.com
